Welcome to NexusRun Studio

    
Build an AI workflow by connecting small steps. Everything runs on your own computer.

    

      
1
Add an agentAn agent is one step. It has instructions, called a prompt, and a model that does the thinking.

      
2
Give it a modelDrag a model from the list on the left onto an agent. Models marked “Fits” run comfortably on this computer.

      
3
Connect agentsDrag from the dot on the right of an agent to another agent. The first one's answer becomes the second one's input.

      
4
Run itPress Run, type a question, and watch each step work. Use Test on a model to check it works before you rely on it.
